## WordPress への投稿手順

1. WordPress 管理画面 → 投稿 → 新規追加
2. タイトルをコピペ
3. 本文をコピペ（Markdown → ビジュアルエディタで貼り付け、または HTML に変換）
4. カテゴリを設定（工具の基礎知識 / レンタル活用術 / DIYハウツー）
5. スラッグを設定（上記ロードマップの値）
6. アイキャッチ画像を設定
7. 公開
