# 内部リンクマップ

記事間を「情報収集→比較検討→購買意図」のファネルでつなぐ設計。
回遊性とSEO評価（トピッククラスター形成）の両方を狙う。

## 設計方針

- 情報収集記事（〜とは・使い方）→ 該当工具のレンタル/比較記事へ送客
- 購買意図記事（レンタル手順）↔ 比較検討記事（購入vsレンタル）は相互リンク
- HC比較記事（13・14）→ ハブ記事（06）へ集約（既設）
- 棚DIY（03）は使用工具（インパクト・サンダー・トリマー）のハブとして機能
