## 高圧洗浄機の基本的な使い方——作業前の準備から片付けまで

### 作業前の準備チェックリスト

- 電源コンセントの場所を確認する（延長コードは最長10mまで）
- 洗浄エリア周辺の鉢植え・自転車・洗濯物を片付ける
- 近隣への水はねを考慮して作業時間帯を選ぶ
- 外壁・塗装面にひび割れや剥がれがないか事前に目視確認する
- 保護メガネ・長袖・長ズボンで肌の露出を最小限に

### ノズルと水圧の基本

| ノズル種類 | 水圧の広がり | 向いている用途 |
|---|---|---|
| 広角（扇形）ノズル | 広く分散 | ベランダ・外壁・車・網戸など広い面 |
| 直線（ジェット）ノズル | 一点集中 | コンクリートの頑固な汚れ・溝の苔 |
| 回転ノズル | 高圧で回転 | コンクリート・タイル・ブロック塀 |

### 基本的な使用手順

1. ホースを接続し、水道を全開にする
2. トリガーを引いて空気を抜いてから電源を入れる
3. まず広角ノズルで試し洗いして水圧と距離を確認する
4. ノズルを対象面から20〜30cm離して一定速度で動かす
5. 作業後は電源を切ってから水道を止め、ホース内の圧力を抜く

## 場所別の使い方と注意点

### ベランダ・バルコニー

最もポピュラーな用途です。年に積もったホコリ・苔・雨汚れが一気に落ちます。排水口の詰まりに注意しながら、奥から手前に向かって水を流すのがきれいに仕上げるコツです。隣や下の階への水はねにも配慮が必要で、洗浄前に排水口の位置を確認しておきましょう。

### 駐車場・コンクリート

オイル汚れや黒ずみには直線ノズルが効果的です。ただし距離が近すぎるとコンクリートの表面を削ってしまうため、20〜30cmの距離を保ちながら動かします。目地（コンクリートの継ぎ目）に直接当てると砂が吹き出すため、目地部分は圧力を弱めるか角度をつけて洗浄します。

### 外壁——使い方を間違えると逆効果

外壁への高圧洗浄は「素材と状態の確認」が最優先です。サイディングや塗装面にひび割れや剥がれがある場合は、高圧洗浄が劣化を加速させるリスクがあります。状態が良好な外壁でも、ノズルを30cm以上離して広角設定で使うのが安全です。

**⚠️ 外壁に高圧洗浄機を使ってはいけないケース**
- コーキング（シーリング）に亀裂や剥がれがある
- 塗装の浮きや粉吹き（チョーキング）が発生している
- タイル目地が劣化しているまたは欠けている
- 木製の外壁・羽目板（水を吸い込んで反りや割れが起きる）
→ これらの状態では高圧洗浄を避け、専門業者に相談を

### 洗車

高圧洗浄機での洗車は、ノズルを車体から必ず50cm以上離すのが大原則です。近すぎると塗装を傷めたり、ゴムモールが剥がれたりします。特に窓のゴムパッキン・サイドミラーの付け根・ドアの隙間には直接当てないようにします。水圧は最低設定から始めて少しずつ上げていくのが安全です。

## 初心者がやりがちな失敗と防ぎ方

| 失敗パターン | 原因 | 防ぎ方 |
|---|---|---|
| 外壁の塗装が剥がれた | ひび割れ箇所に直接当てた | 事前に外壁の状態を確認・ひび割れ部分は避ける |
| コンクリートに傷がついた | ノズルを近づけすぎた | 20〜30cmの距離を保ち、回転ノズルは慎重に |
| 水が室内に入り込んだ | 窓枠や換気口に直接当てた | 窓・換気口の周囲は圧力を落とすか手洗いで |
| 近隣の車や洗濯物を汚した | 周囲の確認不足 | 作業前に半径3mの状況を確認・養生する |
| モーターが焼けた | 連続使用1時間以上 | 1時間ごとに電源を切って休ませる |
| 車の塗装に傷がついた | ノズルが近すぎた・圧力が強すぎた | 50cm以上離して最低圧力から始める |
