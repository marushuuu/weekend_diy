## コメリの工具レンタル——基本情報

| 項目 | 内容 |
|---|---|
| 対応店舗 | 全国92店舗（コメリパワー・コメリPRO） |
| 必要な会員カード | コメリカード（アクアカードは対象外） |
| 本人確認 | コメリカード＋運転免許証が必要 |
| レンタル期間 | 最短1日〜最長7日間 |

**⚠️ コメリカードがないと借りられない**
コメリの工具レンタルはコメリカード会員限定のサービスです。アクアカード会員は対象外。カードをお持ちでない方は店頭またはWebで申込みが必要で、審査を経てカード発行後に初めて利用できます。急ぎで工具が必要な場合はオンラインレンタルのほうが手続きが早いです。

## コメリ工具レンタルの手続きの流れ

### WEB予約の場合
- コメリ公式サイトまたはアプリからレンタル工具を検索
- 在庫がある店舗を選んで希望日時を選択
- コメリカードでログインして予約を確定
- 当日コメリカード＋運転免許証を持参して店頭で受け取り
- 返却期限日に店頭に持参して返却

### 店頭手続きの場合
- コメリカード＋運転免許証を持参して対象店舗へ
- レンタルコーナーで借りたい工具と期間を申告
- 在庫確認後に申込書に記入して料金を支払い
- 工具を受け取ってそのまま持ち帰る

## コメリ工具レンタルの注意点

- 対応店舗が全国92店舗のため、近くにない地域では利用できない
- 店舗によって取り扱い工具が異なる。事前に在庫確認が必須
- コメリカードの審査・発行には数日〜数週間かかる場合がある
- 配送サービスがないため、重い工具は自分で運ぶ必要がある
- 延長する場合は返却前に店舗に連絡が必要
- 高圧洗浄機のような重い機材は往復の運搬が負担になる
