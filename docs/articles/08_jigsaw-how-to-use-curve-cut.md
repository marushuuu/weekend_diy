## ジグソーとは——細い刃を上下させて自由に切る電動ノコギリ

ジグソーは、先端の薄い刃（ブレード）を高速で上下往復させながら材料を切断する電動工具です。ブレードが細くて薄いため、直線だけでなく曲線・円形・複雑な輪郭もそのまま切り抜けるのが最大の特長です。「ジグソーパズル」の名称は、このジグソーで切り出したような複雑な形のピースに由来しています。

**ジグソーでできる主な加工**
- 曲線カット：テーブルの天板・看板・キャラクターの形など自由な輪郭
- 直線カット：丸のこより精度は落ちるが、手軽に板を切れる
- 円形カット：コンパスガイドを使って丸い穴・円形の板を切り抜く
- 中抜き加工：板の中央にコンセント穴・スピーカー穴などを開ける
- 金属・プラスチックのカット：ブレードを替えれば木材以外も対応

## ブレードの種類と選び方——素材と仕上がりで決める

ジグソーの切れ味と仕上がりは、ブレード選びで8割決まります。「どの素材を切るか」と「仕上がりの粗さ」の2軸で選ぶのがコツです。

| ブレードの種類 | 向いている素材 | 仕上がり | 特徴 |
|---|---|---|---|
| 木工用（粗め・山数少ない） | 木材全般 | 粗い | 切断速度優先。下地材・粗切りに |
| 木工用（細め・山数多い） | 木材・合板 | きれい | 仕上げカット・塗装前の切断に |
| 金属用 | 鉄・アルミ・ステンレス | 普通 | 刃が硬く高密度。低速で使う |
| プラスチック用 | アクリル・塩ビ | きれい | 溶けにくい設計。低速推奨 |
| 二重刃（バイメタル） | 木材＋釘・金属混じり | 普通 | 釘が入った古材にも対応 |

### ブレードの「山数（TPI）」が仕上がりを決める

ブレードには「TPI（Teeth Per Inch＝1インチあたりの刃数）」が表記されています。TPIが小さいほど刃が粗く切断速度が速い、TPIが大きいほど刃が細かく切り口がきれいになります。

- 荒切り・スピード重視：6〜10 TPI
- 一般的な木材カット：10〜14 TPI
- 仕上げ・薄い合板・クリーンカット：14〜20 TPI
- 金属・プラスチック：20〜24 TPI以上

## ジグソーの基本的な使い方——曲線カット編

### STEP1：切断線を書く

カットしたい線を材料に鉛筆で書きます。曲線の場合は型紙（テンプレート）を作って写し取るのが最も精度が出る方法です。フリーハンドで書くと線がブレて仕上がりに影響するため、定規・コンパス・型紙を活用しましょう。

### STEP2：材料をしっかり固定する

ジグソーは両手で本体を持つため、材料固定には必ずクランプを使います。材料が動くと切断線がズレるだけでなく、刃が折れる原因にもなります。クランプで2点以上固定し、カットする部分が作業台から外にはみ出す配置にすることで刃の逃げ場を確保します。

### STEP3：ベースプレートを密着させて切り進む

ジグソーの底面にある金属板「ベースプレート」を材料に密着させたまま動かすのが基本姿勢です。ベースプレートが浮くと刃が斜めになり、切断面が傾きます。力を入れすぎず、刃の往復運動に任せてゆっくり前に進めるのがきれいに切るコツです。

**💡 曲線をきれいに切る3つのコツ**
1. 墨線（切断線）の外側1〜2mmをなぞるように切る（ヤスリで仕上げる余地を残す）
2. 急カーブは一度止めて刃を抜き、角度を変えてから再スタート
3. スピードは「中速」に設定。速すぎると刃がブレ、遅すぎると焦げる

## 中抜き加工（板の中央に穴を開ける）の手順

コンセント穴・スピーカー穴・収納の開口部など、板の端からではなく「中央から切り抜く」加工をジグソーで行う方法です。

1. 切り抜きたい形を材料に書く
2. 電動ドリルで「刃が入る大きさの穴」を輪郭内側に開ける（Ø8mm以上が目安）
3. その穴にジグソーのブレードを差し込む
4. 輪郭線に沿ってゆっくり切り進む
5. 角まで切ったら逆方向に切り返して輪郭を完成させる

最初の穴あけには電動ドリルが必要です。ジグソーとドリルのセットがあれば、ほとんどの中抜き加工に対応できます。

## 初心者がやりがちな失敗と防ぎ方

| 失敗パターン | 原因 | 防ぎ方 |
|---|---|---|
| 刃が曲がる・折れる | 無理に押した・速度が速すぎた | 刃の往復に任せてゆっくり進める。急カーブは一度止めて向きを変える |
| 切断面が斜めになった | ベースプレートが浮いていた | ベースプレートを常に材料に密着させる |
| 曲線がガタガタになった | スピードが速すぎた・線を見ていなかった | 中速で動かし、常に切断線を目で追う |
| 材料が割れた | 出口側を支えていなかった | カットが終わる側を手で支えるか、当て木をする |
| 切り始めがガタつく | スタート時に本体が不安定だった | ベースプレートをしっかり材料に当ててから電源を入れる |
| 木材の表面が欠ける | 刃の上方向への動きで割れが出た | 「下向きカット用ブレード」を使うか、マスキングテープを貼ってから切る |
