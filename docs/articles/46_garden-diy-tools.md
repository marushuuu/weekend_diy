# 庭・外構のDIYに必要な工具｜砂利敷き・植栽・花壇の作り方と使う道具

外構・庭のDIYは業者に依頼すると数十万〜数百万円になることがあります。しかし砂利敷き・花壇の縁石設置・フェンス・小さいウッドデッキなら、DIYで大幅にコストを削減できます。この記事では外構・庭DIYで使う工具を作業別に整理します。

**この記事でわかること**
- 外構DIYの主な作業カテゴリと必要工具
- 電動工具が必要な作業・手工具で対応できる作業の分け方
- コンクリート・砂利・植栽の基本的な手順
- レンタルが有効な工具の種類

|-----|--------|---------|
| 砂利敷き | ★☆☆ | スコップ・トンボ（手工具のみ） |
| 花壇の縁石設置 | ★★☆ | ゴムハンマー・スコップ |

## 電動工具なしでできる外構DIY

### 砂利敷き

**必要なもの**：スコップ・熊手・トンボ・防草シート・スリット砂利  
**電動工具**：不要

**手順概要**：
1. 地面をスコップで整地（凸凹をならす）
2. 防草シートを敷いてピンで固定
3. 砂利を均等に敷く（目安5〜7cm厚）
4. トンボで表面を平らにならす

砂利は重くて運搬が大変ですが、作業自体は電動工具なしで完結します。

### 花壇の縁石設置

**必要なもの**：ゴムハンマー・水平器・巻き尺・縁石またはレンガ  
**電動工具**：なくてOK

**手順概要**：
1. 花壇の形と縁石の位置を決める
2. スコップで縁石を埋める溝を掘る
3. 砂を均して縁石を並べる
4. ゴムハンマーで叩いて高さ・水平を整える

## 電動工具があると効率的な外構DIY

### ウッドフェンス・ウッドデッキ

インパクトドライバー・丸ノコ・電動サンダーが必要です。詳しくは別記事「外構フェンスDIY」「ウッドデッキDIY」を参照してください。

### レンガ・石畳の切断加工

特殊な形に合わせてレンガを切断する場合はアングルグラインダー（ディスクグラインダー）またはレンガカッターが必要です。

**注意**：レンガの切断は粉塵が多く、保護眼鏡・防塵マスクが必須です。

## 庭木の剪定・伐採

### 手工具で対応できる場合

- 直径3cm以下の枝：剪定ばさみ
- 直径3〜10cm：剪定のこぎり

### 電動工具が必要な場合

- 直径10cm以上の枝・幹：電動レシプロソーまたはチェーンソー
- 高い場所の枝払い：高枝切りばさみ（手動）または高所作業用ポールソー

## コンクリート土間打ち（簡易版）

駐車場・犬走り（家の周りの薄いコンクリート）などを自分で打設する方法です。

### 必要なもの

| 材料・工具 | 用途 |
|----------|-----|
| インスタントセメント | 簡易版はバケツで混ぜてOK |
| セメントミキサー（レンタル） | 大量の場合 |
| コテ・トンボ | 表面をならす |
| 型枠（木材） | コンクリートの形を決める |
| 砂・砕石 | 基礎 |

**小面積（1〜2m²）**：インスタントセメントをバケツで混ぜて対応可能  
**大面積（3m²以上）**：セメントミキサーのレンタルが現実的

## 庭DIYで使う主な工具のレンタル活用

| 工具 | レンタル有利な理由 |
|-----|-----------------|
| インパクトドライバー | ウッドフェンス・デッキ制作に必須 |
| 丸ノコ | 木材カット工程のみ使用 |
| ハンマードリル | コンクリートへのアンカー固定 |
| 高圧洗浄機 | 既存コンクリートの洗浄 |
| セメントミキサー | 土間打ちの場合のみ |

庭・外構DIYは季節性が高く（春〜初夏・秋が中心）、年1〜2回のプロジェクトのために工具を購入するより、レンタルで対応する方がコスパが高いです。

---

## まとめ

庭・外構DIYは砂利敷き・花壇設置など手工具で完結する作業も多いですが、フェンス・ウッドデッキなど大型プロジェクトには電動工具が必要です。電動工具は年1〜2回のプロジェクトのためにレンタルし、スコップ・ゴムハンマーなどの手工具は購入して手元に置くのが最もコスパの良い選択です。
