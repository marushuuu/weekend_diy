# 外構フェンスDIYに必要な工具｜ウッドフェンス・メッシュフェンスの設置手順

フェンスの外構費用は業者に依頼すると数十万円になることが珍しくありません。DIYで設置できれば材料費だけで済み、数万円以下で完成させることも可能です。この記事では外構フェンスDIYに必要な工具と設置手順を解説します。

**この記事でわかること**
- ウッドフェンスとメッシュフェンスの違いと選び方
- 設置に必要な工具リスト
- 支柱の固定方法（独立基礎とフェンスブロック）
- 板張りから仕上げまでの手順

---

## フェンスの種類と選び方

### ウッドフェンス（木製）

**メリット**：温かみのある見た目・DIYしやすい・デザインの自由度が高い  
**デメリット**：腐食・劣化する（定期的なメンテナンスが必要）・初期費用がやや高い

**向いている場所**：住宅の庭・目隠しフェンス・プライバシー保護

### メッシュフェンス（金属製）

**メリット**：耐久性が高い・メンテナンスが少ない  
**デメリット**：目隠しにならない・冷たい印象

**向いている場所**：駐車場の境界・隣家との境界・低いフェンス

## 支柱の固定方法

フェンス設置で最も重要なのが支柱の固定です。支柱が倒れると全てのフェンスが崩れます。

### 方法1：フェンスブロック＋モルタル固定

最も一般的なDIYでの設置方法です。

**材料**：フェンスブロック（穴付きコンクリートブロック）・モルタル・支柱（アルミまたは木材）

**手順**：
1. フェンスブロックの設置位置を決め、水糸で直線を出す
2. 地面をスコップで掘り、砂利を敷いて転圧する（基礎の高さ＋10cm程度）
3. フェンスブロックを水平に設置する（水平器で確認）
4. ブロックの穴に支柱を差し込み、水平・垂直を確認しながらモルタルを充填する
5. 支柱を仮固定（添え木・ロープ）して48時間以上養生する

### 方法2：独立基礎（コンクリート打設）

支柱をコンクリートで埋め込む方法。強度が最も高い。

**材料**：インスタントセメント・バケツ・型枠（丸筒など）

**手順**：
1. 支柱の位置に深さ40〜50cmの穴を掘る（直径30cm程度）
2. 支柱を立てて水平・垂直を確認
3. 穴にインスタントセメントを流し込む
4. 支柱の垂直を維持しながら48時間以上養生

### 方法3：既存コンクリートへのアンカー固定

駐車場のコンクリートなど、既存の基礎にフェンスを設置する方法です。

**手順**：
1. ハンマードリルでコンクリートにアンカー用の穴をあける
2. ケミカルアンカーまたはメカニカルアンカーを打ち込む
3. フェンス支柱のベースプレートをボルトで固定する

## ウッドフェンスの板張り手順

### 横板張り（最も一般的）

1. **支柱間に胴縁（どうぶち）を取り付ける**：横板を固定するための縦方向の下地材。支柱から支柱へ水平に渡します。
2. **最下段の横板から取り付けていく**：地面から最低5cm以上空けて（通気・腐食防止）最下段を取り付けます。
3. **隙間を一定に保って張る**：板の間隔はスペーサー（端材）を使って一定に揃えます。
4. **ビス打ち**：各板を胴縁にインパクトドライバーでビス固定します。下穴をあけると割れにくくなります。
5. **上端を揃える**：仕上がりの高さに合わせて最上段で高さを調整します。

### 縦板張り

板を縦方向に並べるスタイル。目隠し効果が高く、スタイリッシュな仕上がりになります。胴縁は横方向に複数本渡します（下・中・上の3か所が一般的）。

## 塗装・仕上げ

ウッドフェンスは施工後に防腐塗料の塗装が必須です。

**塗装手順**：
1. 電動サンダー（#120→#180）で表面を研磨する
2. 木くずを拭き取る
3. 防腐・防虫・防カビ効果のある木材保護塗料を刷毛で塗る
4. 乾燥後に2回目を塗る（通常2〜3回塗り重ねる）

**おすすめ塗料**：キシラデコール・バトン・オスモカラーなど浸透性の木材保護塗料

---

## まとめ

外構フェンスのDIYは支柱の固定が最大の難所です。支柱の垂直・水平が正確に出れば、板張りは誰でも進められます。コンクリートへの穴あけが必要な場合はハンマードリルをレンタルしてください。ウッドフェンスの仕上げには丸ノコ・インパクトドライバー・電動サンダーの3つがあると作業効率が大きく上がります。
