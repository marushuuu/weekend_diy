# 電動サンダーの番手（紙やすり）選び方｜塗装前の下地処理を完全解説

「塗装がすぐ剥がれた」「木材の表面がざらざらのまま」——これらの失敗の多くは、サンディング（研磨）工程の番手選びのミスが原因です。電動サンダーを使う上で、紙やすりの番手を正しく選ぶことは仕上がりを左右する重要なポイントです。この記事では塗装前の下地処理から仕上げまで、工程別の番手選びを解説します。

**この記事でわかること**
- 紙やすり（サンドペーパー）の番手の意味
- 塗装前の下地処理で使うべき番手の順番
- 用途別（木材の目地落とし・塗り替え・金属）の番手選び
- 電動サンダーの種類別の特徴と使い分け

---

## 番手（グリット数）とは

紙やすりの粗さを示す数値です。数字が小さいほど粗く、大きいほど細かいです。

| 番手 | 粗さの目安 | 主な用途 |
|-----|----------|---------|
| #40〜#60 | 超粗目 | 旧塗装の剥離・木材の大きな凸凹取り |
| #80 | 粗目 | 荒削り・形成加工後の整形 |
| #120 | 中目 | 表面整形・塗装前の下地処理（1回目） |
| #180〜#240 | 細目 | 塗装前の下地処理（2回目）・ヤニ落とし |
| #320〜#400 | 極細 | 塗装の層間研磨・最終仕上げ |
| #600〜#1000 | 超細 | 金属の磨き・ウレタン塗装の仕上げ研磨 |

---

## 塗装前の下地処理（基本の手順）

### 新材（塗ったことがない木材）への塗装前

**推奨順番**：#120 → #180〜#240

**手順**：
1. #120で表面の毛羽立ち・粗さを取り除く（逆目・ざらつきを消す）
2. #180〜#240で表面を平滑に整える
3. サンディング後は必ず木くずをきれいに拭き取る（塗料と木くずが混ざると仕上がりが汚くなる）
4. 水性塗料を使う場合は、1回目の塗装後に表面が毛羽立つので、乾燥後に#240でもう一度軽くサンディングする

**注意**：#80以下は使わないこと。粗い傷が残ると塗装しても傷が透けて見えます。

---

### 旧塗装の上から塗り替える場合

**推奨順番**：#80〜#120（旧塗装剥離）→ #180〜#240（平滑化）

**手順**：
1. 旧塗装が密着しているか確認（密着していれば上から塗装可能・剥がれているなら剥離が必要）
2. 旧塗装を剥がしたい場合は#80で大まかに削り取る
3. 旧塗装の上から塗り重ねる場合は#120で表面を荒らして（目荒らし）塗料の密着を高める
4. #180〜#240で整えてから塗装

**目荒らし（キズをつけること）の重要性**：ツルツルの旧塗装面に新しい塗料を塗っても密着しません。#120〜#150で意図的に細かい傷をつけることで塗料が食いつきやすくなります。

---

### ウッドデッキ（屋外木材）の塗り替え

屋外木材は紫外線・雨風で旧塗料が膨れたり剥がれたりします。

**推奨順番**：#60〜#80（旧塗装・劣化層の除去）→ #120（整形）→ #180（仕上げ）

**ポイント**：屋外木材は広面積なため、ランダムオービタルサンダーよりベルトサンダーの方が効率的です。ただし削りすぎると木材を傷めるので力のかけすぎに注意してください。

---

## 用途別の番手選びまとめ

| 用途 | 推奨番手の順番 |
|-----|-------------|
| 新材への水性塗料 | #120 → #240 → 塗装 → 乾燥 → #240 |
| 新材へのオイル・ワックス | #120 → #180 → #240 |
| 旧塗装の目荒らし（塗り重ね） | #120 → #180 |
| 旧塗装の剥離（塗り直し） | #60 → #120 → #180 |
| ウッドデッキの再塗装 | #60 → #120 → #180 |
| 家具の仕上げ（素地仕上げ） | #180 → #240 → #320 |
| 金属のサビ落とし | #80 → #150 |

## 電動サンダーの種類と番手の関係

### ランダムオービタルサンダー（最も汎用）

回転しながら楕円形に動く動作で、木目に沿わなくても傷が残りにくいのが特徴です。

**対応番手**：#80〜#400  
**向いている用途**：塗装前の下地処理・家具の仕上げ・広い面の研磨

### オービタルサンダー（四角形のペーパーを使う）

長方形のシートを使うため、端部・角に近い場所も研磨できます。

**対応番手**：#80〜#320  
**向いている用途**：フラットな面の仕上げ・コスパ重視

### ベルトサンダー（帯状のペーパーが回転）

強力で広面積を素早く削れます。プロ向けで、使い方を誤ると削りすぎる危険があります。

**対応番手**：#40〜#120  
**向いている用途**：粗削り・旧塗装の剥離・広面積のウッドデッキ

### 細部用サンダー（マルチツール・デルタサンダー）

三角形の先端で、角や細かい場所を研磨できます。

**対応番手**：#80〜#240  
**向いている用途**：棚の内側・家具の細部

## サンディングのよくある失敗と対策

### 失敗1：塗装後に毛羽立ちが出た
**原因**：水性塗料は木材の繊維を立ち上げる（水引け）  
**対策**：1回目の塗装乾燥後に#240で軽くサンディングしてから2回目を塗る

### 失敗2：旧塗装の上の新塗料がすぐ剥がれた
**原因**：目荒らしが不足していた  
**対策**：塗り重ねる前に必ず#120〜#150で表面を荒らす

### 失敗3：木材の端が大きく削れてしまった
**原因**：ベルトサンダーを端部で強く押しつけた  
**対策**：端部には圧力をかけず、中央から端へ抜けるように動かす

### 失敗4：サンディング後に傷（スクラッチ）が目立つ
**原因**：粗い番手から急に細かい番手に飛んだ  
**対策**：番手は#80→#120→#180→#240と段階的に上げる（2段階以上飛ばさない）

---

## まとめ

電動サンダーの番手選びは、塗装の仕上がりに直結します。基本は「粗い番手で整形→細かい番手で仕上げ」の順番で、2段階以上飛ばさないことが大切です。塗装前には最低でも#120→#240の2工程を経ることで、塗料の密着と表面の滑らかさが格段に向上します。
