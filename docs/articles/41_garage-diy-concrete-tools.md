# ガレージDIYに必要な工具｜コンクリート床・壁パネル・棚の設置を解説

ガレージはDIYで大幅に使いやすく改良できるスペースです。壁に有孔ボードを設置してツールボードを作る・コンクリート床にアンカーを打って棚を固定する・天井から収納を吊るすなど、様々なカスタマイズが可能です。この記事ではガレージDIYに必要な工具と主要な作業の手順を解説します。

**この記事でわかること**
- ガレージDIYの主な作業カテゴリと必要工具
- コンクリート床・壁へのアンカー固定の方法
- 有孔ボード（ペグボード）の設置手順
- DIY棚の組み立て方

## ガレージDIYで人気の改造アイデア

1. **壁面の収納化**：有孔ボード・スラットウォール・すのこを使った壁面収納
2. **工具棚・作業台**：DIYで作る作業台（ワークベンチ）
3. **天井収納**：タイヤ・アウトドア用品の天井吊り収納
4. **コンクリート床の塗装**：エポキシ塗料で床を一新
5. **電気設備**：照明の増設・コンセントの追加（電気工事士の資格が必要）

## コンクリートへのアンカー固定

ガレージの床・壁がコンクリートの場合、棚・ラック・有孔ボードを固定するには「アンカー」が必要です。

### アンカーの種類

| アンカー種類 | 特徴 | 向いている用途 |
|-----------|------|-------------|
| プラグアンカー | 安価・簡単 | 軽量物の固定（〜10kg） |
| カールアンカー | 汎用性高い | 中程度の荷重（〜50kg） |
| ケミカルアンカー | 最強 | 重量物（棚・ラック） |
| オールアンカー（拡張式） | 取り外し可能 | 繰り返し使う場所 |

### アンカー固定の手順（カールアンカーの場合）

1. **穴あけ位置のマーキング**：ビスの位置を鉛筆でマーキング
2. **鉄筋探知機で確認**（RC造の場合）
3. **ハンマードリルで穴あけ**：アンカーの指定径・深さで穴をあける
4. **穴の清掃**：エアダスターで粉塵を除去
5. **アンカーの打ち込み**：ハンマーでアンカーを穴に打ち込む
6. **ボルトで固定**：アンカーにボルトを締め込むとアンカーが拡張して固定される

## 有孔ボード（ペグボード）の設置

有孔ボードは工具の壁面収納として最もコスパが高い方法です。

### 必要なもの

- 有孔ボード（ホームセンターで販売）
- ペグフック各種（フック・シェルフ・トレイ）
- 胴縁（有孔ボードを壁に固定するための下地材）
- ビス・アンカー（壁の材質に合わせる）
- インパクトドライバー

### なぜ胴縁（下地材）が必要か

有孔ボードは壁から5cm以上浮かせて設置する必要があります。ペグフックが孔に差し込めるスペースが必要なためです。直接壁に貼ると孔が使えません。

### 設置手順

1. **胴縁の取り付け位置を決める**：有孔ボードの四隅と中央に対応する位置
2. **胴縁をコンクリート壁に固定する**：ハンマードリルで穴あけ→アンカー固定
3. **有孔ボードを胴縁に固定する**：インパクトドライバーでビス止め
4. **ペグフックを差し込む**：好みに合わせてフックやシェルフを配置

## DIY棚の組み立て

ガレージの作業スペース効率を高める壁面棚のDIY手順です。

### 設計のポイント

- **耐荷重を考慮する**：工具・ペンキ缶など重量物を載せるなら、棚板厚みを2×6材（38mm×140mm）以上にする
- **棚の高さ**：最上段は立った状態で手が届く高さ（通常180cm以下）
- **奥行き**：一般的な工具箱に対応した40〜60cmが使いやすい

### 材料と工具

| 材料 | 仕様例 |
|-----|--------|
| 棚柱（支柱） | 2×4材 または アルミアングル |
| 棚板 | 2×6材 または OSB（構造用合板） |
| 棚受け | アルミまたは木製ブラケット |
| ビス | コーススレッド75mm |

### 組み立て手順

1. **支柱の固定**：コンクリート壁にアンカーを打ち、支柱（2×4材）を固定
2. **棚受けの取り付け**：支柱に棚受けブラケットをビス固定（水平器で確認）
3. **棚板の設置**：棚受けの上に棚板を乗せてビス固定
4. **仕上げ塗装**（オプション）：棚板にオイル塗装またはペイントをして完成

## ガレージ床のコンクリート塗装

コンクリート床をエポキシ塗料で仕上げると、油汚れが落としやすくなり見た目もスッキリします。

### 必要な工具

- 電動サンダー（#60〜#80で表面を研磨）
- 角型ブラシ・ローラー
- 脱脂剤（塗料の密着を高める）

### 手順概要

1. 床を徹底的に清掃・脱脂する
2. ひびや穴をモルタルで補修し、乾燥させる
3. 電動サンダーで表面を研磨（目荒らし）
4. エポキシ下塗り材を塗る
5. 乾燥後にエポキシ仕上げ材を塗る
6. 必要に応じてチップ（装飾材）を散らす

## まとめ

ガレージDIYで最も多い作業は「コンクリートへのアンカー固定」です。ハンマードリルとアンカーの組み合わせを覚えれば、棚・有孔ボード・固定式収納を自由に追加できるようになります。コンクリートへの穴あけが必要な作業が複数ある場合は、ハンマードリルをレンタルして一気に作業を完了させることをおすすめします。
