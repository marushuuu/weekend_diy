# コーナン・コメリ・ナフコの工具レンタルを比較｜料金・種類・オンラインとの違いまで解説

「近くのホームセンターで工具を借りたい」——そう思って調べると、ホームセンターによってサービスの有無・料金・借りられる工具の種類がバラバラで困った経験はありませんか。この記事では、コーナン・コメリ・ナフコ・DCMの工具レンタルサービスを一覧で整理し、オンラインレンタルとの違いも含めて選び方の基準を明確にします。

**この記事でわかること**
- コーナン・コメリ・ナフコ・DCMの工具レンタル有無と料金
- 各ホームセンターが借りられる工具の種類と特徴
- 店頭レンタルとオンラインレンタルの使い分け基準
- 「近くのホームセンターが対応していない」場合の最善の代替手段

## まず結論——ホームセンターの工具レンタル対応状況

| ホームセンター | レンタル有無 | 会員条件 | 最長レンタル期間 |
|---|---|---|---|
| コーナン（ビーバートザン） | ◎ あり | コーナンPay会員で半額 | 5泊6日 |
| コメリ | ◎ あり | コメリカード会員限定 | 要確認（店舗による） |
| DCM（カーマ・ホーマック等） | ◎ あり（一部店舗） | 不要（店頭申込） | 店舗による |
| ナフコ | ✕ なし | —— | —— |
| カインズ | ◎ あり | 不要 | 2泊3日 |
| ビバホーム | △ 工具は対象外 | —— | —— |

ナフコは工具レンタルサービス自体を提供していません。ビバホームはレンタルサービスがありますが、電動工具は対象外です。「コーナン工具レンタル」「ナフコ工具レンタル」で検索してたどり着いた方は、この時点でホームセンター以外の選択肢を検討する必要があります。

## コーナンの工具レンタル——ビーバートザン店舗が中心

### 借りられる工具と料金

コーナンの工具レンタルはビーバートザンブランドの店舗が中心です。ブラック・アンド・デッカーのマルチツールを採用しており、本体1台にドライバー・ジグソー・丸のこ・サンダーなど複数のヘッドを付け替えて使えるのが特徴です。

| 工具カテゴリ | 料金目安（2泊3日） | コーナンPay半額後 |
|---|---|---|
| 充電ドリルドライバー | 300〜500円程度 | 150〜250円程度 |
| マルチツール（各種ヘッド） | 店舗による | 店舗による |
| その他電動工具 | 店舗により異なる | 要問い合わせ |

**💡 コーナンPay会員なら実質半額**
コーナンPayプラスチックカードまたはアプリのモバイルカードを提示すると、基本料金（2泊3日）が半額になります。※PRO・ホームストック・キャンプデポ店舗は対象外。延長料金は割引なし。

### コーナンの注意点
- レンタル可能な工具の種類・料金は店舗ごとに異なる
- 在庫は実店舗に依存するため、借りたい日に在庫がないケースがある
- 最長5泊6日のため、週をまたぐ工事や長期プロジェクトには不向き

## コメリの工具レンタル——カード会員限定だが品揃えが豊富

### 借りられる工具と料金

コメリの工具レンタルはコメリカード会員限定のサービスです。インパクトドライバー・丸のこ・グラインダー・ドリルなど電動工具に加え、高圧洗浄機・チェーンソー・草刈機など大型機械まで揃っているのが強みです。

| 工具カテゴリ | 料金目安（1日） |
|---|---|
| インパクトドライバー | 580円〜 |
| 丸のこ | 580円〜 |
| 高圧洗浄機 | 1,980円〜 |
| 発電機 | 5,280〜11,800円 |
| チェーンソー・草刈機 | 店舗による |

### コメリの注意点
- コメリカード会員でなければ利用不可（カード発行には審査あり）
- WEB予約ができる店舗もあるが、対応状況は店舗による
- 品揃えはホームセンターの中では充実しているが、ニッチな工具は扱いが少ない

## DCMの工具レンタル——会員不要で借りやすいが店舗限定

DCM（カーマ・ホーマック・ダイキなど複数ブランドが統合）のレンタルは会員資格不要で借りられる点が使いやすいです。ただしすべてのDCM店舗が対応しているわけではなく、レンタル工具を置いていない店舗もあります。借りる前に対象店舗かどうかの確認が必要です。

| DCMで借りられる主な工具 | 特徴 |
|---|---|
| 電動ドリルドライバー（コード式・充電式） | 基本工具として多くの店舗に常備 |
| 振動ドリル | コンクリートへの穴あけ用 |
| 電動丸のこ | 木材カット用 |
| 電動ジグソー | 曲線カット用 |
| ディスクグラインダー | 金属・コンクリート研削用 |
| 仕上げサンダー・電気カンナ | 一部店舗のみ |
