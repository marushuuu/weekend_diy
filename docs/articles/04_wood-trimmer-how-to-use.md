棚に溝を彫る、板の角をなめらかな丸みに仕上げる、蝶番を埋め込む……これらをすべてこなせる電動工具があります。「トリマー」です。DIYをある程度続けていると必ず名前が出てくる工具ですが、「なんとなく難しそう」「自分には早い」と後回しにしている方も多いはず。この記事では、トリマーがどんな工具なのか、何ができるのか、どう使えば失敗しないのかを一から解説します。

## 木工トリマーとは——刃を回転させて木材を「削り整える」工具

トリマーの語源は英語の「trim（刈り取る・美しく整える）」です。ペットのトリマーや写真のトリミングと同じ語源で、木工の世界では「木材の余分な部分を削り取って形を整える」電動工具を指します。

仕組みはシンプルで、先端のビット（刃）が高速回転（約3万回転/分）することで木材を削ります。ビットの形状を変えることで、面取りから溝掘り、型抜きまで幅広い加工が1台でこなせます。

**トリマーでできる主な加工**
- 面取り（ボーズ面・角面・ギンナン面など）：板の角を滑らかに仕上げる
- 溝切り：板の表面に直線や曲線の溝を彫る
- 切り抜き：テンプレートに沿って形を切り抜く
- 蝶番の掘り込み：蝶番を埋め込むための座ぐり加工
- 倣い加工：テンプレートと同じ形を量産する

### ルーターとの違いは「サイズ」

トリマーに似た工具に「ルーター」があります。どちらも回転する刃で木材を削る工具ですが、ルーターは出力が大きくビット軸径も太い（12mm前後）のに対し、トリマーはコンパクトで軸径6mmが標準です。DIYでの家具製作や小物の加工ならトリマーで十分対応できます。

## トリマーで使うビットの種類——まずこの3本から始める

トリマーはビットを交換することで加工の種類が変わります。種類は数十種類以上ありますが、初心者が最初に揃えるべきは以下の3本です。

| ビット名 | 何ができるか | 最初に買うべきか |
|---|---|---|
| ストレートビット | 直線の溝を彫る・板の端を垂直に削る | ◎ 必須 |
| ボーズ面ビット（丸面） | 板の角を丸く仕上げる。ローラー付きで削りすぎない | ◎ 必須 |
| 45°角面ビット | 板の角を45度にカットしてシャープに仕上げる | ○ 次に揃える |
| ギンナン面ビット | 銀杏の断面のような緩やかなS字カーブを作る | △ 慣れてから |
| 目地払いビット | 2枚の板の高さをぴったり揃える。ローラー付き | ○ 次に揃える |

### ビット選びの落とし穴：軸径を必ず確認

トリマーのコレットチャック（ビットを固定する部分）の軸径は6mmが国内標準ですが、海外製ビットには6.35mm軸のものも多くあります。購入前に手持ちのトリマーの軸径を確認しないと、差し込めないという事態になります。まずは6mm軸のビットセットを揃えるのが安全です。

## トリマーの基本的な使い方——面取り編

### STEP1：ビットを取り付ける

必ず電源を抜いた状態で作業します。コレットナットをスパナで緩め、ビットを差し込みます。このとき1.5cm以上はチャックにかませるのが基本です。浅すぎると作業中にビットが抜けて危険です。しっかり奥まで入れてからナットを締め直します。

### STEP2：切り込み深さを設定する

ベース部分を回転させてビットの突き出し量を調整します。面取り用ビットの場合は、ローラー（ベアリング）が材料の側面に当たることで深さが自動的に決まるため、深さ設定は不要な機種もあります。溝切り加工の場合は、1回の切削を3mm以内に抑えるのが基本です。深く彫りたい場合は複数回に分けて少しずつ進めます。

### STEP3：送り方向を守って動かす

トリマーを動かす方向には「正しい向き」があります。材料がトリマーの左側にくるように置き、手前から奥に向かって（反時計回りに）動かすのが基本です。この方向を逆にすると「蹴り返し」が起きて材料が飛んだり、仕上がりが荒れたりします。

**⚠️ 速度と蹴り返しに注意**
- 動かすスピードが速すぎると切削面が荒れる
- 遅すぎると摩擦で材料が焦げる
- 逆方向に動かすと蹴り返しが起きて危険
→ 端材で練習してから本番材料に使うのが確実

## トリマーの使い方——溝切り編

溝切りはストレートビットを使います。面取りと違いローラーがないため、ガイドを使って直線を保つのがポイントです。

### ストレートガイドを使う

多くのトリマーには「ストレートガイド（平行ガイド）」が付属しています。材料の端からの距離を一定に保ちながら溝を彫れる便利な治具です。ただし材料の端から離れた場所の溝には届かないため、その場合は別途ガイド板をクランプで固定して対応します。

### 溝は浅く・複数回で彫る

一度に深く彫ろうとすると、ビットに過負荷がかかって折れたり、切削面が荒れたりします。1回につき2〜3mmずつ深さを増やしながら仕上げていくのが正攻法です。急がば回れ、が溝切りの鉄則です。

## 初心者がやりがちな失敗と防ぎ方

| 失敗パターン | 原因 | 防ぎ方 |
|---|---|---|
| 切削面が焦げる | トリマーを動かすスピードが遅すぎる | 一定のスピードを保ちながら動かす。端材で練習する |
| 仕上がりが荒れる | スピードが速すぎる・ビットが鈍くなっている | ゆっくり均一に動かす。ビットの状態を確認する |
| ビットが抜ける | チャックへの差し込みが浅かった | ビットを1.5cm以上差し込み、ナットをしっかり締める |
| 材料が動いてしまう | クランプで固定していない | 必ずクランプで2点以上固定してから作業する |
| 溝が曲がる | ガイドなしでフリーハンドで動かした | ストレートガイドまたはガイド板をクランプで固定する |
| 角の出口で欠ける | 出口側に当て木をしていない | 加工の出口側に同厚の端材を当てて支える |

## トリマー作業の安全対策——必ず守ること

- 保護メガネを必ず着用する（切削くずが目に入ると危険）
- 集じん袋またはバキュームを接続して粉じん対策をする
- ビット交換は必ず電源を抜いた状態で行う
- 材料はクランプで確実に固定してから作業する
