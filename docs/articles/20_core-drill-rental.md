# コアドリル・コンクリートドリルをレンタルする方法｜エアコンスリーブ・配管穴あけの料金と手順

エアコンの取り付けで壁に丸い貫通穴を開ける、給排水管を通すための大径穴を開ける——こうした「コンクリートや外壁に大きな丸穴を開ける」作業に使うのがコアドリル（コア抜きドリル）です。

## コアドリルとハンマードリルの違い

| 比較 | コアドリル | ハンマードリル（通常） |
|---|---|---|
| 開けられる穴径 | Ø40〜200mm以上の大径 | Ø4〜25mm程度の小径 |
| 使う刃 | ダイヤモンドコアビット | SDSプラスドリルビット |
| 水を使うか | 湿式（水を流しながら）が多い | 不要 |
| 代表的な用途 | エアコンスリーブ・配管貫通 | アンカー下穴・小径穴あけ |

**💡 エアコン取り付けのスリーブ穴はコアドリル一択**
エアコンのスリーブ管を通す穴は通常Ø70〜80mm。ハンマードリルの穴あけ範囲を大幅に超えるため、コアドリルが必要です。

## エアコンスリーブ穴あけの基本手順

1. 室内外の配管ルートを確認し、壁内の配線・断熱材を下地センサーでチェック
2. 穴あけ位置を墨出し（室内側から外側に向けて若干下向きに傾ける）
3. 養生シートを敷き、水受け容器を準備する
4. コアビットをセットして低速で穴あけ開始（水を流しながら）
5. 室内側から外側に向けて貫通させる
6. スリーブ管を挿入してパテで隙間を埋める

**⚠️ 必ず事前確認が必要なこと**
- 壁内の電気配線・ガス管・水道管の位置（下地センサーで確認）
- マンション・集合住宅では管理規約・管理組合への確認が必要
- RC構造の場合は鉄筋位置の確認も必要

## よくある質問

**ハンマードリルでエアコンの穴は開けられますか？**
開けられません。ハンマードリルの穴あけ範囲はØ4〜25mm程度で、エアコンスリーブに必要なØ70〜80mmの大径穴には対応できません。コアドリルが必要です。

**マンションでも使えますか？**
管理規約で外壁・コンクリートへの穴あけが制限されている場合があります。必ず事前に管理組合・管理会社に確認してください。RC構造の場合は鉄筋位置の確認も必要です。

**賃貸住宅では？**
原則として原状回復義務があるため、貸主の許可なく穴あけはできません。エアコン設置の場合は既存のスリーブ穴を利用するか、貸主に相談してください。
