# みんなの工具レンタル｜サービス全体フロー

---

## 1. サービス概要

| 項目 | 内容 |
|------|------|
| サービス名 | みんなの工具レンタル |
| URL | https://weekend-diy.com |
| 対象 | DIY初心者・個人向け工具レンタル |
| 配送 | ゆうパック（北海道・沖縄・離島除く） |
| 決済 | Stripe（クレジットカード） |
| 料金 | 1週間¥4,900〜、2週目以降30%OFF |
| 送料 | 3,000円以上のご注文で無料 |

---

## 2. 顧客フロー

```
サイト訪問
    ↓
商品ページを確認（/products/{slug}/）
    ↓
トップページで日程・週数を選択
    ↓
在庫確認（自動）
    ↓
顧客情報入力（氏名・住所・電話番号）
    ↓
Stripeでクレジットカード決済
    ↓
予約番号発行（KR-XXXXXX形式）
予約確認メール受信
    ↓
商品到着（ゆうパック・最短翌日）
    ↓
工具を使用
    ↓
返却期限日（消印有効）までにゆうパックで返送
    ↓
受取・検品完了 → レンタル終了
```

---

## 3. 運営者（管理画面）フロー

```
注文確認（管理画面 → レンタル一覧）
    ↓
梱包・発送準備
 └ 工具本体・充電器・バッテリー・返却用伝票を同梱
    ↓
ゆうパックで発送
    ↓
追跡番号を管理画面に入力
 └ ステータス: confirmed → shipped_to_customer
    ↓
顧客に発送通知メール（自動送信）
    ↓
返却期限3日前：リマインダーメール（自動）
    ↓
返却物受取・検品
 └ 問題なし → ステータス: returned
 └ 損傷あり  → damage_fee を設定して記録
    ↓
（延滞の場合）延滞料金を記録・請求
    ↓
完了
```

---

## 4. ステータス遷移

```
pending
（決済処理中）
    ↓
confirmed
（予約確定・入金済み）
    ↓
shipped_to_customer
（発送済み）
    ↓
active
（使用中）
    ↓
return_evidence_submitted ※任意
（返却証跡提出）
    ↓
returned
（返却完了）

※ 期限超過で overdue に自動移行（cron）
※ キャンセルは cancelled
```

---

## 5. 在庫管理ロジック

```
在庫ユニット（物理的な1台ごと）
    ↓
貸出予約が入ると該当ユニットをブロック
    ↓
ブロック期間 = レンタル開始日 〜 返却期限日 + バッファ日数（4日）
 └ バッファ内訳: 郵送3日 + 検品1日
    ↓
バッファ期間終了後に次の貸し出しが可能
```

**例）返却期限 6/1 の場合**

| 日付 | 状態 |
|------|------|
| 〜6/1 | レンタル中 |
| 6/2〜6/5 | 返送・検品バッファ |
| 6/6〜 | 次の貸し出し可能 |

## 6. 料金計算

```
レンタル料金 = 1週間料金 × 週数（2週目以降は×0.7）

例）3週間レンタル（¥4,900/週）
 1週目: ¥4,900
 2週目: ¥3,430（30%OFF）
 3週目: ¥3,430（30%OFF）
 合計:  ¥11,760

送料:
 注文合計 3,000円未満 → ¥2,500
 注文合計 3,000円以上 → 無料
```

## 9. システム構成

```
WordPress（テーマ: minna-kogu）
    └ カスタムプラグイン: kogu-rental
        ├ 商品管理（DB: kogu_products）
        ├ 在庫管理（DB: kogu_inventory）
        ├ レンタル管理（DB: kogu_rentals）
        ├ 購入オプション管理（DB: kogu_addon_products / kogu_rental_addons）
        ├ Stripe決済（class-stripe-handler.php）
        ├ メール通知（class-email-handler.php / SendGrid）
        └ 定期処理（class-cron.php）
            ├ 延滞チェック（毎日）
            └ リマインダー送信（毎日）
```

## 10. 管理画面メニュー

| メニュー | 内容 |
|----------|------|

| 購入履歴 | 購入オプションの販売履歴・返品管理 |
| 設定 | Stripe APIキー・SendGrid・バッファ日数・GTM等 |
